# Nova Iorque: 1992

RPG narrativo de investigação e horror urbano, baseado em um sistema autoral de RPG de mesa. Um jogador conduz um grupo de até quatro protagonistas; os demais são controlados por IA de acordo com sua personalidade, e o narrador local conduz as cenas.

## Como rodar

Requer Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Abra o endereço indicado (normalmente http://localhost:5173).

## Verificações

```bash
npm test
```

```bash
npm run typecheck
```

```bash
npm run build
```

## O que dá para jogar

Capítulo de demonstração **“O desaparecimento de Thomas Reed”**: prólogo, formação do grupo, a visita de Victoria Whitmore, o prédio da Rua 78 Leste, o apartamento 5C, um confronto que pode ser evitado, e um encerramento provisório com ganchos para as investigações do Bellevue e do Village Voice.
